# Piano samples (grand piano)

88-key _Musyng Kite_ General-MIDI soundfont samples, per-note MP3s bundled for
offline playback in the app (no network needed).

- Source: <https://github.com/gleitz/midi-js-soundfonts> (`MusyngKite/acoustic_grand_piano-mp3`),
  generated from the Musyng Kite soundfont
  (<http://www.synthfont.com/SoundFonts/Musyng.sfpack>).
- Instrument: Acoustic Grand Piano (General MIDI program 0)
- License: **CC BY-SA 3.0**
  ([Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/)).
  The midi-js-soundfonts project lists Musyng Kite under that license.
  Attribution: credit the Musyng Kite soundfont and the
  [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) project,
  and link this license. Share-alike: adaptations of these samples must be
  distributed under CC BY-SA 3.0 as well.
- 88 files, ~1.65 MB total, flat-note naming (C, Db, D, Eb, E, F, Gb, G, Ab, A, Bb, B).

The midi→file map lives in `src/audio/piano-map.generated.ts` (generated).
