# Piano samples (grand piano)

88-key _Musyng Kite_ General-MIDI soundfont samples, per-note MP3s bundled for
offline playback in the app (no network needed).

- Source: <https://github.com/gleitz/midi-js-soundfonts> (`MusyngKite/acoustic_grand_piano-mp3`)
- Instrument: Acoustic Grand Piano (General MIDI program 0)
- License: Musyng Kite is a General-MIDI soundfont by Ogg Vorbis/Musyng Kite;
  redistributed under the soundfont's permissive terms (see the source repo).
- 88 files, ~1.65 MB total, flat-note naming (C, Db, D, Eb, E, F, Gb, G, Ab, A, Bb, B).

The midi→file map lives in `src/audio/piano-map.generated.ts` (generated).
